ESP32 Board Versions and Capabilities
====================================

Overview
--------
ESP32 board versions primarily differ by the underlying Espressif chip
(original ESP32, S-series, C-series, H-series, P-series, etc.).
Development boards (DevKitC, NodeMCU-style, SuperMini, etc.) are built
around modules (WROOM, WROVER, MINI, etc.) that contain one of these chips,
plus flash, optional PSRAM, antenna, and USB circuitry.

Exact GPIO count, flash size, and PSRAM vary by specific module/board.
Always check the datasheet or board docs for pinouts and available pins.

Notes on Common Boards
----------------------
- ESP32-DevKitC / NodeMCU-32S style — Original ESP32 (WROOM-32 or similar). Most Arduino tutorials target this.
- ESP32-S3-DevKitC — Current recommended general-purpose board (USB-C, optional PSRAM).
- ESP32-C3-DevKit / SuperMini — Low-cost Wi-Fi + BLE.
- ESP32-C6-DevKit — For Matter/Thread/Zigbee experiments.
- WROVER modules — Include PSRAM (useful for displays, cameras, buffering).
- ESP32-CAM — Original ESP32 + OV2640 camera (limited pins, external programmer often needed).

Quick Selection Guide
---------------------
- General Arduino / ESPHome / IoT     → ESP32-S3 (with PSRAM if using displays/cameras)
- Cheapest Wi-Fi + BLE sensor         → ESP32-C3
- Matter / Thread / Zigbee            → ESP32-C6 (or H2 if no Wi-Fi needed)
- 5 GHz Wi-Fi                         → ESP32-C5
- Bluetooth Classic (audio, classic SPP) → Original ESP32 (or S31 when widely available)
- Large displays / high performance / no radio → ESP32-P4
- First board / maximum tutorial compatibility → Original ESP32 DevKitC or ESP32-S3 DevKitC

Notes
-----
Capabilities evolve. Always verify the exact module revision and datasheet
for your board, especially for power modes, available GPIOs, and radio features.
Official Espressif chip comparator and datasheets are the best primary sources.
