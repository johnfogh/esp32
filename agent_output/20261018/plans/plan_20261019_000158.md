# Plan: extract devicehostlib from target_editor

## Goal
Create sibling Rust library `~/dev/esp32/devicehostlib` and move host-side device interaction out of `target_editor`. `target_editor` depends on it via path.

## New crate
- Path: `/home/jff/dev/esp32/devicehostlib`
- Package: `devicehostlib` 0.1.0, edition 2024, `publish = false`
- Own `.git` (like scriptlib/targetlib/reportslib); local init only (no GitHub remote unless asked)
- Layout: `Cargo.toml`, `src/lib.rs`, `.gitignore`, `rust-toolchain.toml` (stable), short `README.md`
- Deps: `utils` (path `../utils`, features `["host"]`), `bluer`, `tokio` (rt-multi-thread, macros, sync, time, net, io-util), `futures`, `uuid`, `serde`+`serde_json`, `chrono`

## Move into devicehostlib (as public modules)
From `target_editor/src/`:
- `central.rs` — OS-paired BlueZ GATT host
- `devices.rs` — devices.json load/save
- `sensor.rs` — virtual Hub/Board
- `local.rs` — in-process attach + Unix socket
- `protocol.rs` — status buffer + command dispatch
- `roster.rs` — roster/sock paths + Guard

`lib.rs` re-exports these modules.

## Split from `ctrl.rs` (device types only)
Move into devicehostlib (e.g. `src/linked.rs` or under `devices`):
- `Linked`, `LastMsg`
- helpers: `virt_ingest_default`, `parse_sensors`, `cmp_ts_keys`, `newest_sample`, `last_sample_from_line`, `parse_accel`, `ingest_sample`, `apply_telemetry`

Leave in `target_editor` `ctrl.rs`:
- `App`, `Focus`, `Tab`, `DevEdit`, `Cmd`, `Msg`, key/theme/flash UI state
- `handle_ble` / rename / enabled stay on `App`, using lib types

## target_editor changes
- Add `devicehostlib = { path = "../devicehostlib" }` to `Cargo.toml`
- Drop `mod central|devices|sensor|local|protocol|roster` and delete those files
- Replace `crate::{central,devices,sensor,local,protocol,roster,ctrl::Linked,...}` with `devicehostlib::...` (and `ctrl::Linked` → lib)
- Keep `utils` if still needed for flash/`Chip`; drop unused deps only if nothing else uses them
- Update Device Flash `list_projects` exclude list to include `devicehostlib` (and leave `devicelib` alone — empty sibling, out of scope)
- README one-liner: host device stack lives in `devicehostlib`

## Out of scope
- Empty `devicelib/` directory
- GitHub remote / push
- cargo build/test (unless asked)
- Moving `virt_ui.rs` / `ui_manager.rs` / `ui_roster.rs` (UI stays; they import the lib)
